# Dourado Comunicação

Plataforma web de alta performance desenvolvida para a apresentação e venda de soluções em presença digital da **Dourado Comunicação**. O site apresenta serviços especializados no desenvolvimento de Landing Pages focadas em conversão, websites institucionais modernos e otimização estratégica do perfil no Google Meu Negócio.

---

## 🛠️ Tecnologias Utilizadas

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
- **Estilização:** [Tailwind CSS](https://tailwindcss.com/) + CSS Variables
- **Otimização de Fontes:** `next/font` (Inter Font)
- **Ícones:** [Lucide React](https://lucide.dev/)

---

## ⚙️ Como Rodar o Projeto

### Pré-requisitos

Certifique-se de ter o **Node.js** (versão 18.17 ou superior) e um gerenciador de pacotes (`npm`, `pnpm` ou `yarn`) instalados em sua máquina.

### Passo a Passo
 **Clonar o repositório:**

```bash
git clone git@github.com:samirdourado//douradocomunicacao.git
```

## Iniciando

Instalar as dependencias:

```bash
npm install
```

## Iniciando

Rodar o servidor de desenvolvimento:

```bash
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000) com seu navegador e ver o resultado.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
